# Branch Rules

- Vor Start von Story/Ticket Branch-Entscheidung einholen (wenn keine Präferenz gesetzt); dafür bevorzugt ein verfügbares Tool für strukturierte Nutzereingaben nutzen, damit Codex ein Popup/Choice-Fenster anzeigt.
- Branch-Namen:
  - `ticket/ticket-001-short-title`
  - `story/story-001-short-title`
- Wenn Branch-Erstellung scheitert: transparent melden.
